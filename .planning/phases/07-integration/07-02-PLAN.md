    1. **test_limit_rad()** — tests tools::limit_rad:
       - limit_rad(M_PI) == -M_PI (pi wraps to -pi)
       - limit_rad(-M_PI) == -M_PI (-pi stays at -pi)
       - limit_rad(0.0) == 0.0
       - limit_rad(3 * M_PI / 2) approx -M_PI / 2 (270deg wraps to -90deg)
       - Use approx_equal helper with 1e-6 epsilon

    2. **test_delta_time()** — tests tools::delta_time:
       - Create two steady_clock::time_points 100ms apart
       - delta_time should be approximately 0.1 (tolerance 1e-3)

    3. **test_lightbar_vertical()** — tests Lightbar from cv::RotatedRect:
       - Create cv::RotatedRect(Point2f(120, 240), Size2f(40, 280), 0) -- vertical bar
       - Construct Lightbar from it
       - Verify angle_error < 0.1 (vertical bar has near-zero angle error)
       - Verify length approximately 280 (tolerance 10)
       - Verify ratio approximately 7.0 (280/40, tolerance 1.0)

    4. **test_armor_pairing()** — tests Armor construction from two Lightbars:
       - Create two vertical lightbars: left at (120, 240), right at (520, 240)
       - Both bars: 40x280, vertical, with matching colors
       - Construct Armor(left_lb, right_lb)
       - Verify center.x approximately 320 (midpoint tolerance 10)
       - Verify center.y approximately 240 (tolerance 10)
       - Verify armor.points.size() == 4

    5. **test_trajectory()** — tests tools::Trajectory:
       - Construct Trajectory(23.0, 10.0, 0.5) -- v0=23m/s, d=10m, h=0.5m
       - Verify !traj.unsolvable
       - Verify traj.fly_time > 0

    6. **test_ekf_1d()** — tests tools::ExtendedKalmanFilter:
       - Initialize 1D EKF with x0={0.0}, P0=Identity
       - Use identity matrices for F, H; Q=0.01*I, R=0.1*I
       - Predict with F, Q
       - Update with observation z={1.0}, H, R
       - After one predict-update cycle, state x[0] should be > 0.5

    7. **test_detector_synthetic_armor()** — conditional full-pipeline test:
       - Parse config at ../../config/auto_aim.toml
       - Read classify_model path from config
       - If model path is empty or file doesn't exist: print [SKIP] message and return
       - Construct Detector(config_path, false) -- debug=false to avoid any imshow calls
       - Create 640x480 black cv::Mat
       - Draw two white vertical rectangles for light bars:
         - Left: cv::Rect(100, 100, 40, 280) -- cv::rectangle with cv::FILLED
         - Right: cv::Rect(500, 100, 40, 280)
       - Call detector.detect(img, 0)
       - Verify !armors.empty()
       - Print [PASS] with detected armor count
