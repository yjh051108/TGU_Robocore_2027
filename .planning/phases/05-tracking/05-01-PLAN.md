      const Eigen::VectorXd & x0, const Eigen::MatrixXd & P0,
      std::function<Eigen::VectorXd(const Eigen::VectorXd &, const Eigen::VectorXd &)> x_add)

    Calls the non-linear overload with `f(x) = F * x`.

    **5. predict(F, Q, f) -- preserve identically:**
    P = F * P * F^T + Q, x = f(x)

    **6. update(z, H, R) -- preserve identically:**
    Calls the non-linear overload with `h(x) = H * x` and default z_subtract.

    **7. update(z, H, R, h, z_subtract) -- preserve identically (key function, includes NIS):**
    - Joseph form covariance update for numerical stability: P = (I - KH) * P * (I - KH)^T + K * R * K^T
    - State update with custom x_add: x = x_add(x, K * z_subtract(z, h(x)))
    - NIS chi-squared test: residual = z_subtract(z, h(x)), S = H*P*H^T + R, nis = residual^T * S^{-1} * residual
    - NEES computation: (x - x_prior)^T * P^{-1} * (x - x_prior)
    - Thresholds: nis_threshold = 0.711, nees_threshold = 0.711 (dof=4, 95% confidence)
    - Sliding window: push NIS pass/fail (1/0), pop front if > window_size, compute recent failure rate
    - Populate data map with residual_yaw/pitch/distance/angle, nis, nees, recent_nis_failures

    **8. Keep #include <numeric>** for std::accumulate in sliding window sum.

    **No changes needed:**
    - All source code is pure Eigen math -- no logging, no config, no name changes
    - The NIS threshold (0.711) stays the same (dof=4 chi-squared inverse CDF at 95%)
