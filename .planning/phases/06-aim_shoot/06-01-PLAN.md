    Everything else in trajectory.cpp is unchanged: `#include <cmath>`, `constexpr double g = 9.7833;`, `namespace tools { ... }`, and the full constructor body with quadratic solution, delta check, pitch selection (shorter fly_time), fly_time calculation.

    The math is:
    ```
    delta = d^2 - 4 * (g*d^2/(2*v0^2)) * (g*d^2/(2*v0^2) + h)
    tan_pitch = (-d ± sqrt(delta)) / (2 * g*d^2/(2*v0^2))
    pitch = atan(tan_pitch)
    fly_time = d / (v0 * cos(pitch))
    ```
    Selects the solution with shorter fly_time. If delta < 0, unsolvable = true.

    Verify the cpp includes "tools/trajectory.hpp" (not "trajectory.hpp").
