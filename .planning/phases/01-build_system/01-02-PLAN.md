    ```cmake
    cmake_minimum_required(VERSION 3.16)

    add_library(tools STATIC
        crc.cpp
        logger.cpp
        foxglove_comm.cpp
    )

    target_include_directories(tools PUBLIC
        ${PROJECT_SOURCE_DIR}
        ${PROJECT_SOURCE_DIR}/tools/foxglove/include
    )

    target_link_directories(tools PUBLIC
        ${PROJECT_SOURCE_DIR}/tools/foxglove/lib
    )

        foxglove
        Boost::boost
        pthread
    )
    ```

    - `foxglove` resolves to libfoxglove.a or libfoxglove.so via target_link_directories
    - Foxglove include path needed for `#include "foxglove/server.hpp"` in foxglove_comm.cpp
    - `Boost::boost` per D-03; the vendored foxglove statically links Boost internally
    - `pthread` per D-03; nm analysis confirmed vendored foxglove .so has pthread symbol dependencies
    - Both include/link paths are PUBLIC so downstream targets (test executables) can resolve
